📋 Требования 
Перед началом работы убедитесь, что у вас установлены: 
JDK 17 или выше, Maven 3.8 или выше, Git, Браузер (Chrome/Firefox по умолчанию), Allure Commandline (для генерации отчетов)

🚀 Быстрый старт

Клонируйте проект: git clone или cd IFQA_Filimonova
Соберите проект: mvn clean install
Запустите тесты: mvn clean test
Откройте отчет: allure serve target/allure-results
Вы великолепны!
