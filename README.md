Проект автоматизации тестирования JUnit 5 + Allure

🛠 Технологический стек
- Java 17
- Maven 3.8
- Selenide 7.3.2
- Allure 2.25.0
- JUnit 5.10.2

📋 Требования
Перед началом работы убедитесь, что у вас установлены:
JDK 17 или выше
Maven 3.8 или выше
Git
Браузер (Chrome/Firefox по умолчанию)
Allure Commandline (для генерации отчетов)

🚀 Быстрый старт
1. Клонируйте проект
git clone <repository-url>
cd IFQA_Filimonova
2. Соберите проект
mvn clean install
3. Запустите тесты
mvn clean test
4. Откройте отчет
allure serve target/allure-results
5. Вы великолепны!
